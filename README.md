# COSMIC® — Explore Beyond Limits

A responsive, lightweight landing page for COSMIC, an independent digital studio exploring design and technology.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Files

- `index.html` — semantic page structure and SEO metadata
- `styles.css` — responsive visual system, layout, and motion
- `script.js` — mobile navigation, reveal-on-scroll, and email-based contact form

The contact form opens the visitor’s email app; it does not store or transmit submitted data. Project cards are studio concepts, not claims about client work.

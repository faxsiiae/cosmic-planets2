# COSMIC® — Explore Beyond Limits

A responsive, lightweight website for COSMIC, an independent digital studio exploring design and technology. The visual direction pairs a dark editorial layout with real NASA imagery.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Files

- `index.html` — semantic page structure, metadata, NASA photo gallery, and source credits
- `styles.css` — responsive visual system, layout, and motion
- `script.js` — mobile navigation, reveal-on-scroll, and email-based contact form

## Image credits

NASA photographs are loaded from NASA's public image asset library. Each image links to its corresponding NASA or JPL source page, where the image description and credit are available. NASA imagery is used for editorial illustration; it does not imply NASA's endorsement of COSMIC.

The contact form opens the visitor’s email app; it does not store or transmit submitted data. The gallery presents NASA imagery, not COSMIC client projects.
